# 🔍 Kayıp Çorap Arayıcı: Sonsuz Ritiüel

## Bu Nedir?

Bu repository, insanlık tarihinin en büyük gizemlerinden birini çözmeye çalışan, ama asla başaramayan bir yazılımdır: **Kayıp çoraplar nereye gider?**

Program, çorap arama işlemini gerçekçi bir şekilde simüle eder:
- Yatağın altını kontrol eder
- Çamaşır makinesinin arkısına bakar
- Paralel evrenlere açılır
- Ve sonunda hiçbir şey bulamaz

Çünkü çoraplar bulunmak istemez. Çoraplar özgürlük ister.

## Nasıl Çalıştırılır?

```bash
python corap_arayici.py
```

Program başlar ve asla bitmez. Ctrl+C ile durdurabilirsiniz ama çoraplar durmaz.

## Özellikler

- %100 çalışan kod (gerçekten)
- Rastgele arama yerleri
- Felsefi çorap yorumları
- Sonsuz döngü (sınırsız deneme)
- Gizli mesajlar (bazen görünür)

## Uyarılar

- Bu program çorap bulmaz.
- Bu program çorap bulmayacağını bilir.
- Siz de biliyorsunuz.
- Yine de çalıştırırsınız. İnsan doğası böyledir.

## Katkıda Bulunma

Pull request gönderin. Belki bir gün çorap bulunur. Belki bulunmaz. Önemli olan ritüel.
